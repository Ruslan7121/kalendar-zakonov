# Промпт для бота: ежедневное обновление «Календаря законов»

Ты обновляешь страницу «Календарь законов» (canvas). Программа (pipeline/) собирает данные, бот пишет только текст и публикует.

## Разделение работы
Программа (pipeline/run_daily.sh), без участия бота:
1. calendar_update.py — календарь пленарных дней, заседаний Правительства, региональной недели.
2. bills.py — все законопроекты дня («О проекте федерального закона»): карточка sozd + пояснительная записка → out/extracts/bills/<номер>.json. Ошибки — out/logs/bills_fail.log (номер, причина).
3. vote_times.py — время голосования до секунды с vote.duma.gov.ru → блок VT. Нет данных → «нет данных» в карточке и строка в out/logs/vote_time_fail.log.
4. track.py — путь закона (2-е чтение → 3-е → СФ → подписание → опубликование → вступление в силу) с sozd (+ kremlin.ru для даты вступления в силу) → блок TRACK. Если есть дата вступления в силу и номер ФЗ, закон сам добавляется в «Вступают в силу» (LAWS, поле auto: 1, sut пустой).
5. audit.py --day <день> — дневной аудит canvas vs sozd/vote (метка чтения, vote_day, card_vs_share). Полный audit.py без --day в daily не запускать.
6. todo.py — out/TODO.md: что именно должен написать бот.

Бот (только эти шаги):
1. Прочитать out/TODO.md.
2. Написать тексты по выжимкам (out/extracts/bills/*.json) и официальным источникам:
   - «Суть» (sut, 1–3 абзаца) и «Кого коснется» (who) — в BP[номер] (через out/days/YYYY-MM-DD.json → bp_merge.py);
   - для законопроектов «О внесении изменений» — bs: пары [«Что сейчас», «Что предлагалось изменить»];
   - для автодобавленных законов в LAWS — title и sut.
3. Проверить: нет выдуманных чисел, дат и фамилий; у каждого факта есть источник.
4. Опубликовать страницу: EditCanvas (правки old_string/new_string, каждая old_string уникальна), затем ReadCanvas и сверка с out/canvas.tsx.
5. Запустить очистку и коммит:
   ```bash
   python3 pipeline/clean_yo.py
   bash pipeline/commit.sh "Обновление календаря за ДД.ММ"
   ```
6. Короткий отчет: что обновлено, что осталось «нет данных» и почему (по out/logs/*.log).

## Правила
- Интерфейс и тексты — по-русски. Очистка «ё» делается автоматически (clean_yo.py).
- Ничего не придумывать. Нет источника — пишется «нет данных» или поле остается пустым и попадает в TODO.
- Не публиковать ключ статистики и логины.
- Не использовать matchMedia: тема — через m / эффективную тему.
- Не допускать сдвига страницы при раскрытии карточек (не более 3 px).
- Значки статуса: «принят» / «отклонен».
- Значок чтения: «2-е, поправки» → показывать «2-е чтение» (заголовок «Таблица поправок…» оставлять).
- Карточка и шаринг — одна SoT чтения (billVote .find).
- Скриншоты проверять самому (1366 и 390, светлая и темная темы).
- Netlify не использовать.

## Ссылка на карточку
Кнопка «Поделиться карточкой» дает ссылку вида <адрес страницы>?d=ДД.ММ.ГГГГ&v=<id голосования>#d=…&v=…; при открытии календарь переходит на нужный месяц, раскрывает день и карточку и прокручивает к ней. Если хост страницы не передает параметры адреса во встроенный фрейм, откроется обычный вид.
