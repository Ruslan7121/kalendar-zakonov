## 14.11.2026 — данные первой отрисовки скачиваются вместе с кодом

- index.html сразу запрашивает данные первой отрисовки (core + месяц дня/текущий месяц) параллельно с app.js (link rel=preload as=fetch); раньше было три запроса подряд: код → core → месяц.
