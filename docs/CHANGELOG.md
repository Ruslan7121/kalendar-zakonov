### TRACK / данные
- Отклонение отмечает этап чтения, на котором голосовали (r2/r3), а не более ранний accept. Пример: 1180448-7 — sozd GD 28.10.2026 отклонен после текста, принятого в 1-м → TRACK `r2=28.10.2026` (r1 остается 22.03.2022).
- Исправление метки чтения 1180448-7: отклонение→2-е (принятый в первом) по аудиту sozd/vote.

### Pipeline
- `audit.py`: независимый кросс-чек canvas vs sozd/vote (reading, track_date, vote_day, **card_vs_share**); флаг `--day` для дневного среза, `--fix` при необходимости.
- `run_daily.sh`: после track вызывается только `audit.py --day "$DAY"` — полный `audit.py` без `--day` в ежедневный прогон не входит.
- `track.py`: rejection пишет дату в этап голосования (r2/r3).
